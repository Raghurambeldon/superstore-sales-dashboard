# 📊 Superstore Sales Dashboard (Excel)

An interactive **Sales Dashboard built in Microsoft Excel** to analyze retail performance using the Superstore dataset.  
The dashboard transforms raw sales data into meaningful insights using Pivot Tables, Pivot Charts, and interactive slicers.

---

## 🚀 Project Overview

This project focuses on analyzing sales performance across different business dimensions such as **regions, categories, segments, and time trends**.  
The goal is to present key business metrics and insights through an easy-to-understand dashboard.

---


## 📈 Key Metrics

• Total Sales  
• Total Profit  
• Total Quantity Sold  

These KPIs help quickly evaluate overall business performance.

---

## 📊 Dashboard Features

✔ KPI cards displaying key metrics  
✔ Monthly sales trend analysis  
✔ Category-wise sales comparison  
✔ Sub-category performance breakdown  
✔ Regional quantity distribution  
✔ Segment sales contribution  
✔ Interactive slicers for dynamic filtering  

---

## 🛠 Tools & Techniques Used

• Microsoft Excel  
• Pivot Tables  
• Pivot Charts  
• Slicers  
• Data Cleaning with Power Query  
• Data Formatting & Visualization  

---

## 📌 Key Insights

• Technology category generates the highest sales  
• West region records the highest quantity sold  
• Consumer segment contributes the largest share of sales  
• Sales peak during the final months of the year  

---

## 📂 Dataset

The project uses the **Superstore dataset**, commonly used for learning data analysis and visualization.
